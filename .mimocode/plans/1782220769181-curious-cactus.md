# Подключение к реальному API

## Архитектура
- Бэкенд: `http://localhost:3000` (NestJS + PostgreSQL)
- Формат ответа: `{ data: <payload>, timestamp }`
- WebSocket: `ws://localhost:3000` для чата и тикетов

## Поэтапный план

### Этап 1: HTTP-клиент и хуки
- Создать `useQuery` аналог через fetch + useState (или установить @tanstack/react-query)
- Обернуть все запросы в единый `apiClient` с обработкой ошибок и ответа `{ data }`
- Добавить JWT-заголовок для админа

### Этап 2: Замена моков в гостевом приложении
- `Home.tsx`: загружать тикеты, меню, услуги из API
- `OrderForm.tsx`: отправлять POST заявки
- `Chat.tsx`: загружать сообщения + WebSocket
- `GlampInfoContext`: загружать settings из API

### Этап 3: Замена моков в админке
- `Tickets.tsx`: загружать/обновлять тикеты через API
- `Menu.tsx`: CRUD меню через API
- `Services.tsx`: CRUD услуг через API
- `CheckIn.tsx`: check-in/check-out через API
- `Chats.tsx`: сообщения через WebSocket
- `InfoEditor.tsx`: читать/писать settings через API

### Этап 4: WebSocket для реалтайма
- Подключить `useWebSocket` к корню приложений
- Обрабатывать события: task:new, task:updated, message:new, gate:alert

## Порядок
1. types и API клиент (уже готовы)
2. Гость: Home → OrderForm → Chat → Info
3. Админ: Tickets → Menu → Services → CheckIn → Chats → InfoEditor
4. WebSocket
