# Деплой на Render.com — 2 Static Site

## Что делаем

Создаём 2 отдельных Static Site на Render.com:
- `glamping-guest.onrender.com` — планшет гостя
- `glamping-admin.onrender.com` — панель админа

## Шаг 1: Добавить SPA-роутинг

Для React Router нужно, чтобы все пути перенаправлялись на `index.html`.

**Создать файлы:**
- `apps/guest/public/static.json`
- `apps/admin/public/static.json`

```json
{
  "routes": [
    { "src": "/(.*)", "dest": "/index.html" }
  ]
}
```

## Шаг 2: Добавить deploy-скрипт

В root `package.json` добавить:
```json
"start": "serve apps/guest/dist -s -l $PORT",
"start:admin": "serve apps/admin/dist -s -l $PORT"
```

## Шаг 3: Push на GitHub

Всё уже в git. Нужно запушить.

## Шаг 4: Создать Static Site на Render.com

Повторить 2 раза:

**Для гостя:**
- New → Static Site
- Connect GitHub repo: `glamping-frontend`
- Name: `glamping-guest`
- Branch: `main`
- Build Command: `npm install && npm run build:guest`
- Publish Directory: `apps/guest/dist`
- Auto Deploy: Yes

**Для админа:**
- New → Static Site
- Name: `glamping-admin`
- Branch: `main`
- Build Command: `npm install && npm run build:admin`
- Publish Directory: `apps/admin/dist`

## Шаг 5: Проверить

- `https://glamping-guest.onrender.com` — планшет гостя
- `https://glamping-admin.onrender.com` — панель админа

---

## Верификация

1. `npm run build` — оба приложения собраны
2. Push на GitHub
3. Render.com автоматически задеплоит
4. Проверить SPA-роутинг (обновление страницы не должно давать 404)
