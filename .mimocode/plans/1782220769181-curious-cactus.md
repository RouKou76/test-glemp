# Совместимость с Android 7 (Chrome 51)

## Проблема
Android 7 = Chrome 51, не понимает `?.`, `??` и другие ES2020+ фичи. Vite по умолчанию таргетит `esnext`.

## Решение

### 1. `npm install -D @vitejs/plugin-legacy`

### 2. `apps/guest/vite.config.ts` — добавить legacy плагин + build.target
```ts
import legacy from '@vitejs/plugin-legacy'
export default defineConfig({
  plugins: [react(), legacy({ targets: ['chrome >= 51'] })],
  build: { target: 'es2015' },
  ...
})
```

### 3. `apps/admin/vite.config.ts` — аналогично

## Верификация
- `npm run build` — собирается с legacy-чанками
