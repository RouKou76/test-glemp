# PWA: «Добавить на рабочий стол» на Android

## Что нужно для PWA на Android
1. `manifest.json` — обязательный
2. `service-worker.js` — обязателен для показа кнопки «Установить» в Chrome
3. Мета-тег `<link rel="manifest">` в `index.html`
4. HTTPS — уже есть на Render.com

## Файлы

### 1. `apps/guest/public/manifest.json`
```json
{
  "name": "Glamping — Планшет гостя",
  "short_name": "Glamping",
  "start_url": "/",
  "display": "standalone",
  "background_color": "#f2f8f5",
  "theme_color": "#267049",
  "icons": [
    { "src": "/icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icon-512.png", "sizes": "512x512", "type": "image/png" }
  ]
}
```

### 2. `apps/admin/public/manifest.json`
Аналогично, но name: «Glamping — Администратор»

### 3. `apps/guest/public/sw.js` и `apps/admin/public/sw.js`
Простой service worker для кэширования:
```js
const CACHE = 'glamping-v1'
self.addEventListener('install', e => e.waitUntil(caches.open(CACHE).then(c => c.addAll(['/']))))
self.addEventListener('fetch', e => e.respondWith(caches.match(e.request).then(r => r || fetch(e.request))))
```

### 4. Обновить `apps/guest/index.html` и `apps/admin/index.html`
Добавить в `<head>`:
```html
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#267049">
<meta name="apple-mobile-web-app-capable" content="yes">
```
Добавить регистрацию SW в конце `<body>`:
```html
<script>navigator.serviceWorker?.register('/sw.js')</script>
```

### 5. Иконки
Создать SVG-иконки и конвертировать в PNG 192x192 и 512x512, или использовать placeholder.

## Верификация
- `npm run build` — манифест и SW попадают в dist/
- На Android: Chrome → «Добавить на рабочий стол» → приложение открывается без адресной строки
