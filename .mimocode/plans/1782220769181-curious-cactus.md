# Admin CRUD: подключение к API

## Стратегия
Заменить моки на `useApi` + `apiPost`/`apiPut`/`apiDelete` в каждом файле админки.

## Файлы для обновления

### 1. Tickets.tsx
- `mockTasks` → `useApi('/api/tasks')`
- `handleStatusChange` → `apiPost('/api/tasks/:id', { status })`
- `handleArchive` → `apiPost('/api/tasks/:id/cancel', {})`

### 2. Menu.tsx
- `mockMenuItems` → `useApi('/api/menu')`
- `handleSave` → `apiPost('/api/menu', item)` или `apiPut('/api/menu/:id', item)`
- `handleDelete` → `apiDelete('/api/menu/:id')`
- `toggleAvailable` → `apiPut('/api/menu/:id', { isAvailable })`

### 3. Services.tsx
- `mockServices` → `useApi('/api/services')`
- CRUD через apiPost/apiPut/apiDelete

### 4. CheckIn.tsx
- `mockHouses` + `mockGuestSessions` → `useApi('/api/houses')` + `useApi('/api/houses/:id/session')`
- Check-in → `apiPost('/api/houses/:id/check-in', ...)`
- Check-out → `apiPost('/api/houses/:id/check-out')`

### 5. Chats.tsx
- `mockMessages` → `useApi('/api/messages')`
- Отправка → WebSocket `send('client:message:send', ...)`
- WebSocket для получения сообщений

### 6. InfoEditor.tsx
- `GlampInfoContext` → уже подключен через `useGlampInfo()`

## Верификация
- `npx tsc --noEmit` — 0 ошибок
