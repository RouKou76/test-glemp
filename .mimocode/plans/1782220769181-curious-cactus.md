# Стилизованные подтверждения удаления (админ)

## Задача
Заменить нативный `confirm()` на кастомный модал в стиле приложения.

## Решение

### 1. Новый компонент `packages/ui/src/components/ConfirmDialog.tsx`
- Использует `Modal` из @glamping/ui
- Пропсы: `open`, `title`, `message`, `confirmLabel`, `onConfirm`, `onClose`, `variant?: 'danger' | 'primary'`
- UI: иконка (🗑 для удаления), текст, кнопки «Отмена» / «Подтвердить» (красная для danger)

### 2. Экспорт в `packages/ui/src/index.ts`

### 3. Замена `confirm()` в админке
- `apps/admin/src/pages/Menu/Menu.tsx` — handleDelete
- `apps/admin/src/pages/Services/Services.tsx` — handleDelete
- `apps/admin/src/pages/CheckIn/CheckIn.tsx` — handleCheckOut

В каждом: добавить state `deleteTarget`, при клике на удаление показать ConfirmDialog, при подтверждении — выполнить удаление.

## Верификация
- `npx tsc --noEmit` — 0 ошибок
